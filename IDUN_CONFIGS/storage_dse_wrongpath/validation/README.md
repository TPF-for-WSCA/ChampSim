trace, `spec_gcc_001`, with 1,000 warmup and 10,000 ROI instructions. This
short prefix has identical IPC across the configurations and cannot support
performance conclusions. It is not the full 80-point design-space experiment.

for the baseline. Run the parent README's experiment to produce complete plots.
